Pegá acá el vector: un path SVG (con líneas, curvas y/o arcos), el <svg> completo (con uno o varios <path>, se detectan todos solos), o una lista de puntos x,y x,y .... No hace falta borrar nada del código de más.

Si el cuadro no se completó solo, es normal (el navegador a veces bloquea la lectura automática del portapapeles, sobre todo al abrir el archivo directamente sin servidor): pegalo vos con Ctrl+V / Cmd+V.

Se pega usando la escala/posición de referencia guardada (así todos los caracteres del mismo dibujo quedan proporcionados entre sí). Si es el primer pegado, se calcula sola. Después de pegar, podés reescalar y reposicionar con la herramienta Selección. Si cambiaste de dibujo de origen y la referencia ya no corresponde, recalculala acá:

Estado de la fuente

Pluma: clic para agregar puntos; clic cerca del primero (o "Cerrar trazado") cierra la figura y ya podés empezar otro contorno (por ejemplo un agujero) con el próximo clic. Selección: clic sobre un trazado y arrastrá para moverlo — si viene de un mismo pegado con su calado, se mueven juntos; al seleccionar aparece el slider para escalarlo. Nodo: clic sobre un punto y arrastrá para ajustarlo. Las dos líneas punteadas (verde en 0 y azul en el ancho) son los manejadores de ancho: en modo Selección, arrastrá la verde para mover todo el glifo, o la azul para definir el ancho de avance (funciona también en el espacio). El progreso se guarda automáticamente en este navegador.
